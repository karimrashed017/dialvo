# Dialvo brand kit

The logo is a spark: rays of different lengths bursting from one point, like a voice level meter, with the longest pointing at the name.

| Folder | What's in it |
|---|---|
| `svg/` | Vector files (best quality, any size). Each comes in `ink` (black), `white` and `blue`. |
| `png/` | Transparent PNGs of the same files. |
| `covers/` | The logo on the meadow photo: 1920x1080 covers (icon only, and icon + word), social share image 1200x630, X header 1500x500, poster 1080x1350, profile picture and app icon. |

| File | Use |
|---|---|
| `dialvo-logo-*` | Icon + word. The main logo. |
| `dialvo-icon-*` | Icon only. |
| `dialvo-wordmark-*` | Word only. |
| `dialvo-stacked-*` | Icon above the word, for square spaces. |
| `dialvo-app-icon-*` | App icon, square (stores round it) and `-rounded` (websites, decks). |
| `favicon.svg` | Browser tab icon; blue, switches to white in dark mode. |

Colours: blue `#1F3BFF`, ink `#0B0B0C`, white. Typeface: Outfit SemiBold (SIL Open Font License), converted to outlines.
The meadow photo was generated for Dialvo (not a stock or third-party photo).
